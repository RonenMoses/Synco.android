Synco לאנדרואיד – בניית האפליקציה (פעם אחת, בערך 15 דקות, בחינם)
=====================================================================

האפליקציה היא "מעטפת" מאובטחת ל-Synco שלכם: כל שינוי ב-Synco נכנס אליה לבד.
בונים אותה מחדש רק אם הכתובת של Synco משתנה.

מה צריך: חשבון GitHub חינמי (github.com) ואת הקבצים בתיקייה הזו.

1. יוצרים מאגר
   github.com ← הירשמו / התחברו ← למעלה "+" ← New repository
   שם: synco-android · לבחור Public · Create repository.

2. מעלים את הקבצים
   בעמוד המאגר: "uploading an existing file".
   גוררים את כל מה שבתוך התיקייה synco-android (כולל התיקייה .github) ← Commit changes.
   * במק התיקייה .github מוסתרת: ב-Finder לוחצים Cmd+Shift+. כדי לראות אותה.
   * אם בכל זאת לא עלתה – ראו "אם הבנייה לא התחילה" למטה.

3. הכתובת של Synco
   ב-Synco: תפריט הצד ← "אפליקציה לאנדרואיד" ← "העתקה".
   ב-GitHub: לוחצים על synco-url.txt ← העיפרון ← מוחקים הכול ← מדביקים ← Commit changes.

4. מפתח החתימה (פעם אחת)
   Settings ← Secrets and variables ← Actions ← New repository secret
     Name: SIGNING_KEY_B64     Secret: הטקסט הארוך מהקובץ "סודות-חתימה.txt"
     Name: SIGNING_PASSWORD    Secret: הסיסמה מאותו קובץ
   בלי זה האפליקציה עדיין נבנית, אבל כל בנייה חדשה תדרוש להסיר את הקודמת לפני התקנה.

5. הבנייה
   לשונית Actions ← "Build Synco APK" רצה לבד (כ-5 דקות). אם לא – לוחצים עליה ← Run workflow.
   בסיום: בעמוד הראשי של המאגר ← Releases ← Synco.apk.

6. קישור ההורדה לכולם
   הקישור הקבוע:  https://github.com/<שם-המשתמש>/synco-android/releases/latest/download/Synco.apk
   מדביקים אותו ב-Synco ← "אפליקציה לאנדרואיד" ← "קישור הורדה" ← שמירה.
   מעכשיו כל המשתמשים רואים כפתור הורדה וקוד QR.

התקנה בטלפון
------------
מורידים את Synco.apk ← פותחים ← מאשרים "התקנה ממקור זה" (פעם אחת) ← התקנה.
אם Play Protect שואל – "פרטים נוספים" ← "התקנה בכל זאת" (רגיל לאפליקציה פרטית שלא מהחנות).

אם הבנייה לא התחילה
-------------------
Actions ← "set up a workflow yourself" ← מוחקים את מה שכתוב ←
מדביקים את כל התוכן של הקובץ workflow-build.yml ← Commit changes.

מה יש באפליקציה
---------------
• נפתחת רק בכתובת של Synco שלכם. כל קישור אחר (וואטסאפ, טלפון, מייל, אתרים) נפתח באפליקציה המתאימה.
• HTTPS בלבד, Google Safe Browsing, בלי גיבוי של נתוני התחברות, בלי גישה לקבצים במכשיר.
• הורדות (אקסל, PDF, גיבוי) נשמרות בתיקיית ההורדות ← Synco, עם "פתיחה" ו"שיתוף".
• שיתוף (וואטסאפ וכו'), מצלמה לסריקת ברקוד ולצילום, מיקום לשעון הנוכחות – ההרשאה נשאלת רק כשצריך.
• מסך שלא נכבה במצב בישול, מצב כהה לפי המכשיר, כפתור "חזרה" שעובד.
• מתאימה לכל גודל: טלפון, טאבלט, Fold (מעבר בין המסכים בלי לאבד מה שפתוח), Flip, מסך מפוצל וחלון צף.
• אנדרואיד 7 ומעלה.
